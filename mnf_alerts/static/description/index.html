Dynamic Manufacturing Alerts & Notifications

Real-time SQL-based monitoring for Aluminum Production and beyond.

The Goal

The mnf_alerts engine bridges the gap between complex SQL manufacturing data and immediate human action. Instead of checking reports manually, the system monitors your database and pushes alerts directly to the right people.

  • Reduce production errors
  • Monitor aluminum profile quality in real-time
  • Automate follow-ups for low inventory

How to Configure

1. Define Alert Logic

Create an Alert Definition using SQL queries or business rules. This defines what condition triggers the alert.

2. Configure Execution

Link configuration to the alert and set execution interval (minutes/hours) to control frequency and avoid duplicates.

3. Select Users & Channels

Choose users and enable delivery channels: Web Notifications, Email, and Activities.

Alert System Architecture

Each alert works through two connected layers:

Alert Definition (Logic Layer)

  • Defines SQL query or condition
  • Detects business events (low stock, delay)
  • Independent of users or notifications
  • WHAT to detect

Alert Configuration (Delivery Layer)

  • Linked to Alert Definition
  • Selects target users
  • Controls channels:
    • Web Notifications
    • Email Alerts
    • Odoo Activities
  • Controls frequency & anti-spam
  • WHO receives & HOW
