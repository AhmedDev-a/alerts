Dynamic Manufacturing Alerts & Notifications

Real-time SQL-based monitoring for Aluminum Production and beyond.

The Goal

The mnf_alerts engine is designed to bridge the gap between complex SQL manufacturing data and immediate human action. Instead of checking reports manually, this app monitors your database and pushes alerts directly to the right people.

  • Reduce production errors.
  • Monitor aluminum profile density/quality in real-time.
  • Automate follow-ups for low inventory.

How to Configure

1. Define Alert Logic

Create an Alert Definition using SQL queries or business rules. This defines what condition triggers the alert (e.g. low stock, production delay).

2. Configure Execution

Create an Alert Configuration linked to the definition. Set execution interval (Minutes/Hours) to avoid duplicate alerts and control frequency.

3. Select Users & Channels

Choose target Odoo users who will receive alerts. Enable delivery channels such as Web Notifications (Bus), Email, and Activities.

Alert System Architecture

Each alert works through two connected layers:

Alert Definition (Logic Layer)

  • Defines SQL query or condition
  • Detects business events (e.g. low stock, delay)
  • Independent of users or notifications
  • This is WHAT to detect

Alert Configuration (Delivery Layer)

  • Linked to one Alert Definition
  • Selects target users and departments
  • Controls notification channels:
    • Web Notifications
    • Email Alerts
    • Odoo Activities
  • Controls frequency and anti-spam rules
  • This is WHO receives and HOW it is delivered
